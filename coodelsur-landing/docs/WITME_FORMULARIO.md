# Formulario Microcrédito Small — Campos (Witme)

Catálogo de campos para que Witme implemente el formulario. **Sin API por ahora** — la conexión se definirá cuando Coodelsur despliegue la aplicación.

## Documento Word

**[formulario-microcredito-small-campos-witme.docx](./formulario-microcredito-small-campos-witme.docx)**

Regenerar:

```bash
npm run docs:campos-witme
```

## Contenido

- 8 pasos del formulario con tablas (campo, etiqueta, tipo, obligatorio, validación, valores)
- Reglas condicionales (placa, parentesco, otros ingresos, etc.)
- Adjuntos (cédula, video, firma)
- Anexo de listas desplegables
